Gemini Helper is a cross-browser study companion for working through questions and concepts on a webpage. Users can capture a visible area or select text, choose whether to solve, explain, or summarize it, and view Gemini's response in a compact panel on the same page.

The extension connects directly to Google's Gemini API with the user's own key. It has no account system or backend, stores settings only in local browser storage, and does not retain captures or answers. It can discover the compatible Gemini models available to each API key and produces separate builds for Chrome, Edge, Brave, and Firefox.
